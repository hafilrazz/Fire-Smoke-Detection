Developer API
HTTP Endpoints for Developers
GET /api/health

Checks if the service is running and returns model details. 

curl -X GET http://localhost:5000/api/health
POST /api/predict/image

Send an image file to check for fire and smoke. 

curl -X POST -F "file=@test-imgs/fire_sample_01.jpg" http://localhost:5000/api/predict/image
POST /api/predict/frame

Send a camera frame (Base64) for live streaming detection. 

curl -X POST -H "Content-Type: application/json" -d '{"frame": "data:image/jpeg;base64,..."}' http://localhost:5000/api/predict/frame
POST /api/predict/video

Upload a video file to scan for fire and smoke. 

curl -X POST -F "file=@test_video.mp4" -F "sample_interval=0.5" http://localhost:5000/api/predict/video
